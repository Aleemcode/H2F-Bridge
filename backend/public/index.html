Install / test flow

One Chrome extension. One Figma plugin. A short capture loop.

Share this page with testers so they understand exactly what to install, what to click, and what result to expect. No account is required for the beta review flow.

01

Install the Chrome extension

Add H2F Bridge from the Chrome Web Store, then pin it to the toolbar. Open any normal webpage you want to convert.

Open Chrome Store Replace with final listing URL after approval
02

Install the Figma plugin

Add the companion Figma plugin. It reads recent captures from the hosted backend and imports them into the open Figma file.

Open Figma plugin Figma Community companion
03

Capture, refresh, import

Click “Capture Current Page” in Chrome, open the plugin in Figma, click “Refresh”, then import the latest capture as editable layers.

Roadmap

What v2 should unlock.

1

Preset viewport rendering for public URLs, including 1440x1024, tablet, and mobile captures.

3

Team beta with capture retention controls, private .h2d files, and shareable import links.

Privacy posture

Explicit capture. Short retention. No training by default.

This beta is designed around consent: captures are user-triggered, sensitive form fields should be excluded, and private-mode export can keep the conversion local. Before public distribution, the product should ship with deletion controls, a plain-language privacy policy, and capture retention limits.
